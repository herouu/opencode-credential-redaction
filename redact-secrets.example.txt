# credential-redaction 密钥清单
# ============================================================================
# 本文件由插件 ~/.config/opencode/plugin/credential-redaction.ts 读取。
# 每行一条：NAME=VALUE（也支持裸值，自动命名 SECRET_<n>）。
# 空行与以 # 开头的行会被跳过。值长度 < 12 的一律忽略（避免误伤普通字符串）。
#
# 改完**不需要重启**，插件 5s 内自动重载（按 mtime 判断）。
# 调试日志：%TEMP%\opencode\credential-redaction.log（只记变量名/长度，绝不记真值）
# 注意：本文件本身是明文。它等价于「把密钥放在这里让插件用」，不要提交进 git。
#
# 环境变量也会被自动扫描：变量名匹配 API_KEY / TOKEN / SECRET / PASSWORD /
# CREDENTIAL / PRIVATE_KEY / AUTH 且值长度 >= 12 的，自动纳入。

# 示例（按需取消注释）：
# OPENAI_API_KEY=<paste-your-key-here>
# CLOUDFLARE_API_TOKEN=<paste-your-token-here>
# DB_PASSWORD=<paste-your-password-here>
